# 🤝 Projeto Mão Amiga

O **Mão Amiga** é uma plataforma web desenvolvida com o objetivo de facilitar o acesso à saúde para a comunidade LGBT+. O sistema permite a busca por consultas e profissionais inclusivos, além de oferecer um espaço para que novos colaboradores possam se juntar à iniciativa.

Este projeto foi desenvolvido como parte das atividades práticas da disciplina de **Back-End Frameworks**.

### 🏳️‍🌈 Propósito do Projeto
Promover o bem-estar e a saúde institucional, garantindo um ambiente seguro e acolhedor para a busca de serviços médicos e de apoio, alinhado aos conceitos de impacto social e inclusão.

### 🛠️ Tecnologias Utilizadas
* **Front-End:** HTML5 e CSS3 (Design Responsivo)
* **Back-End:** Node.js
* **Banco de Dados:** MySQL (Integração funcional para armazenamento de dados)
* **Ferramentas:** VS Code e MySQL Workbench

### ⚙️ Como o projeto funciona
O sistema utiliza uma estrutura de rotas em Node.js que se conecta a um banco de dados relacional MySQL. Nele, é possível realizar o cadastro de interessados e consultar informações sobre serviços de saúde disponíveis.
